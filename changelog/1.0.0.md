## Modules

### brocktech.dynu_dns.a_record

- Create, Update, and Delete **A** records using the _Dynu DNS_ API.
- Can create multiple records with the same name and different targets but will not add multiple with same target.
- Can limit to one record per name and manage records that way.

### brocktech.dynu_dns.cname_record

- Create, Update, and Delete **CNAME** records using the _Dynu DNS_ API.
- Follows DNS spec and only allows one **CNAME** record per hostname.
