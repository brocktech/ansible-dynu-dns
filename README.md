# Ansible Collection - gsbtech.dynu_dns

*Written By: Curtis Jones [<curtis.jones@brocku.ca>](mailto:curtis.jones@brocku.ca)*


## Modules

Currently this collection only provides one thing: a module for managing
individual A records in Dynu DNS.


### gsbtech.dynu_dns.a_record

Module to manage __A__ records in Dynu DNS through the API.


### gsbtech.dynu_dns.cname_record

Module to manage __CNAME__ records in Dynu DNS through the API.
