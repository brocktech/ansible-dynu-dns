# Ansible Collection - gsbtech.dynu_dns

*Writted By: Curtis Jones [<cjones2@brocku.ca>](mailto:cjones2@brocku.ca)


## Modules

Currently this collection only provides one thing: a module for managing
individual A records in Dynu DNS.


### gsbtech.dynu_dns.module

This module will eventually manage all relevant records in Dynu DNS. However
for now we only require that it manages *"A"* records, so that is it's
limitation.
